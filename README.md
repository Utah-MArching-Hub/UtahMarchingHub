# UtahMarchingHub
Archive Repo for the Utah Marching Hub Website!

This was a project to help post news and scores for the Utah marching arts scene, developed by a few students from different high schools across Utah. With all of us learning and studying computer science in different capacities, this project was a good way for us to put some of the things we learned to use in an easy and low-stakes way. We were able to learn how to work with each other, using the industry standards of collaborative development, and learn the platform of GitHub and version control.
